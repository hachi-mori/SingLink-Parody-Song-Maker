# ローカルの固定4問セット

タイトル画面の「教材を読み込む」でJSONを1本選ぶと、4問と各3択をファイルに記した順で出題します。別のJSONを選ぶとセットを置き換えます。ページ更新・タブ終了後は再読込が必要です。

通常の `records` / `entries` 形式は、従来どおり4問と誤答候補をランダム抽出します。無関係な `format` メタデータも読み込めます。

## 固定セットの形式

ルートに次の項目を指定します。

| 項目 | 値 |
| --- | --- |
| `format` | `singlink-experience-set` |
| `version` | `1` |
| `setId` | 英数字から始まる半角英数字・ハイフン・下線の識別子 |
| `title` | 画面に表示するセット名 |
| `entries` | 下記の問題を4件、出題順に格納 |

各問題には `id`、`answer`、`explanation`、`questionText`、`displayText`、`singingReading`、`choices` を指定します。`questionText` は穴埋め記号 `○○` を1個だけ含み、答えで埋めた文が `displayText` と一致する必要があります。`choices` は重複のない3語で、`answer` を1回含めます。問題IDと正解語はセット内で重複できません。

`setId` または予約済みの `singlink-experience-set` で始まる形式名があるJSONは固定セットとして厳密に検証します。必要項目不足や形式の誤記があっても、通常ランダム教材へ黙って切り替えません。不正な読込では、それまでの教材を保持します。

## 実行と保存

`web` で `npm.cmd run dev` を実行し、`http://127.0.0.1:5173/` を開きます。歌声には同じPCのVOICEVOX（標準ポート50021）が必要です。1問60秒で、時間はJSONや画面から変更できません。正解数にかかわらず4問後に歌を生成します。音声なしの結果では「歌を作り直す」で同じ4問を再試行できます。

教材はタブ内だけに保持します。生成した歌詞・回答・音声はブラウザの履歴に保存され、教材を解除しても残ります。保存に失敗しても生成音声は再生できます。履歴の削除方針は実施者が決めてください。

非公開教材やその音声は `local-only/` に置き、Gitや公開用 `assets` / `dist` に追加しないでください。インポート教材の合成先は同じPCのVOICEVOXに限定されています。

## 確認

`npm.cmd test`、`npm.cmd run typecheck`、`npm.cmd run build` で検証できます。テストには架空教材を使い、非公開教材の本文を含めません。
