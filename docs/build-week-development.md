## 最終機能

- 所有者提供の語彙順を基に、新規作成した例文・意味を持つオノマトペ教材335件
- 英訳例文・英語意味335件
- 歌唱用ひらがな読み335件
- 1プレイ4問
- 5曲
- 4つの正解例文を1例文1フレーズで歌唱
- 英語初期UIと保存される英語・日本語切替
- 英語だけ英訳例文と意味を表示
- `frame_length / 93.75` で導出する文字単位カラオケ同期
- サーバー経路とブラウザ直接経路で共有するScore・合成計画
- 音声・歌詞・回答をIndexedDBへ保存
- 横長、縦長、モバイルのレスポンシブ表示
- GitHub Pagesで実行できる固定4問の事前生成デモ
- デモでは「幸せなら手をたたこう」のScore・伴奏と、VOICEVOX 0.25.1で事前生成したずんだもん歌唱を使用
- 通常モードの回答由来リアルタイム生成と、入力に依存しないデモサンプルを画面上で区別

## 人間が行った重要判断

- カラオケ文化を日本語学習体験へ使う
- 学習者ではなく、ずんだもんが正解を歌う
- 日本語を主情報、英語を補助情報にする
- 出版社教材由来の本文を除去し、例文・意味・歌唱用読みを新規作成する
- 335件と5曲を提出体験の範囲にする
- 1プレイを4問にする
- 提出版は保存値がなければ英語で始める
- 固定タイマーではなく合成Scoreを同期の正本にする
- 実画面への具体的なレイアウトフィードバック
- 審査員が準備なしで価値を確認できる固定デモを追加し、通常モードとの違いを明示する
- デモ専用曲ではなく、プロジェクト内の「幸せなら手をたたこう」のScoreと伴奏を使う

AI生成物を無条件に採用せず、現行コード、テスト、ブラウザ、VOICEVOX出力、Git差分へ照合しました。
