# Codex長時間運用プロンプト

`CODEX_PLAN.md` の未設定項目を埋めてから使用します。角括弧の箇所は今回の内容へ置き換えてください。

## 開始用

```text
あなたは、この長時間作業を管理する親エージェントです。

AGENTS.md、CODEX_PLAN.md、CODEX_STATUS.md、BACKLOG.md、BLOCKERS.md、
git status、直近のコミットと差分を確認してください。

目標は「[具体的な成果]」です。
CODEX_PLAN.mdを仕様、変更範囲、完了条件の正本として扱ってください。
未設定項目や実際の状態との不整合があれば、コードを変更する前に報告してください。

調査役は読み取り専用、同じ変更範囲の実装役は1体、レビュー役は読み取り専用とします。
計画外の問題は修正せずBACKLOG.mdへ、判断が必要な問題はBLOCKERS.mdへ記録してください。

各チェックポイントと中断前にCODEX_STATUS.mdを更新してください。
同一失敗の再試行、レビュー修正、外部操作はAGENTS.mdとCODEX_PLAN.mdの上限・禁止事項に従ってください。

完了条件を満たすか停止条件に該当するまで進め、最後に変更、コミット、確認結果、
エージェントごとの担当、レビュー結果、未解決事項、人間が最初に確認する箇所を報告してください。
```

## 安全な中断用

```text
現在の新しい作業を開始せず、安全な中断準備をしてください。

1. 実行中の書き込み処理や確認コマンドを完了するか安全に停止する
2. git statusと差分を確認する
3. 完結していて安全な変更だけを意味のある単位でコミットする
4. CODEX_STATUS.mdへ次を記録する
   - 完了した内容
   - 未完了の内容
   - 最後に成功した確認
   - 現在のGit状態とコミット
   - 保留事項とブロッカー
   - 再開後の最初の作業
5. パッケージ処理、Git操作、一括変換などが実行中でないことを確認する
6. 中断可能になったら作業を止めて報告する
```

## 再開用

```text
AGENTS.md、CODEX_PLAN.md、CODEX_STATUS.md、BACKLOG.md、BLOCKERS.md、
git status、直近のコミットと差分を確認してください。

記録と実際の状態が一致することを、コードを変更する前に確認してください。
不整合があれば修正を始めず報告してください。

整合している場合は、CODEX_STATUS.mdの「再開後の最初の作業」から再開し、
CODEX_PLAN.mdの範囲、上限、完了条件、停止条件を引き続き守ってください。
```

## 60分の事前訓練

一晩の運用前に、次を一度通して確認します。

1. 小さな目標を1件だけ `CODEX_PLAN.md` に設定する
2. 開始用プロンプトで30～40分作業する
3. 安全な中断用プロンプトを送る
4. Codexアプリを終了し、再起動する
5. 再開用プロンプトを送る
6. 状態の不整合なく完了できることを確認する
7. 作業後に不要なWorktreeとタスクを整理する
